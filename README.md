## 📚 Topics Covered

| Topic                | Description                                                     |
| -------------------- | --------------------------------------------------------------- |
| ⚙️ **Event Loop**    | `setTimeout`, `setImmediate`, `process.nextTick`, `fs.readFile` |
| 📡 **Event Emitter** | `myEmitter.on()` and `myEmitter.emit()` patterns                |
| 🌐 **HTTP Server**   | Creating servers with `http.createServer()`                     |
| 🌊 **Streams**       | `fs.createReadStream().pipe(res)` for efficient I/O             |
| 📦 **Modules**       | `module.exports` and `exports` patterns                         |
| 🔐 **Crypto**        | `crypto.pbkdf2Sync` and `crypto.pbkdf2` usage                   |
